Week 5 – JavaScript DOM Manipulation

Overview

This repository contains my Week 5 coursework for IYF Weekend Academy Season 12. The focus of this week was learning how to use JavaScript to interact with HTML elements, respond to user events, and dynamically update webpage content.

Topics Covered

- DOM selection and manipulation
- Changing HTML content and attributes
- Modifying CSS styles using JavaScript
- Creating and removing HTML elements
- Handling click, keyboard, and form events
- Event bubbling and event delegation
- Form handling and validation
- Working with event objects and keyboard shortcuts

Main Project: Interactive To-Do List

The To-Do List application allows users to:

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Filter tasks by status
- View the number of remaining tasks
- Clear completed tasks
- Edit tasks using double-click

Technologies Used

- HTML5
- CSS3
- JavaScript

Daily DOM Challenges

This repository also includes five daily challenges:

1. Color Changer – Changes an element's background color through user interaction.
2. Element Creator – Creates new HTML elements dynamically.
3. Image Remover – Removes an image from the webpage.
4. Content Copier – Copies content through a button interaction.
5. Dark Mode – Toggles between light and dark display modes.

How to Run the Projects

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open the relevant HTML file.
4. Run it using Live Server or open it in a browser.
